# GPU 컨테이너 재생성 후 복구

정리 기준: 2026-10-29. 안내된 서버 작업은 2026-10-30 17:00–18:00 (한국시간)입니다.

## 저장 위치와 범위

코드 정리 전 파일은 원래 `/NHNHOME/WORKSPACE/` 작업공간에 보존하며,
작업공간의 `maintenance_backups/pre_mig_*/`에 별도 백업을 만듭니다.
`maintenance_backups/LATEST`에 해당 백업 폴더명이 기록됩니다.
백업에는 실제 데이터·학습 결과·로컬 설정이 있으므로 외부에 게시하지 마세요.

- `GEAS.tar`: GEAS 작업 폴더의 소스·데이터·결과·로컬 설정.
- AX 백업 범위·파일명은 로컬 백업의 최종 `BACKUP_SUMMARY.md`를 확인하세요.
  전체 AX 작업공간은 약 765GiB이며, 과거 시험별 중간 파일을 제외한 별도 백업에서는
  원시 데이터·최종 결과·진행 중 학습 상태를 보존하고 제외 목록을 함께 기록합니다.
- `*.tar.sha256`: 백업 파일 검증값.
- `*_inventory.json`, `*_backup_result.json`, `*_tar.log`: 목록, 완료 상태와 경고.
- `*_uncommitted.patch`, `*_head.txt`, `*_branches.txt`: 정리 전 Git 상태.
- `private_runtime/`: 로컬 환경 설정. 읽기 권한을 제한합니다.
- `python311_packages.txt`, `gpu_before_mig.txt`: 환경 복원 참고 자료.

`.git`, 가상환경, Python·테스트 캐시는 TAR 대상에서 제외합니다.
Git 이력은 원격 저장소와 원래 작업 폴더에, 가상환경은 기존 영구 작업공간에 남습니다.
이 백업은 같은 영구 저장소 안의 별도 복사본이며 외부 재해복구 백업은 아닙니다.

## 검증과 복원

1. `*_backup_result.json`과 TAR 로그를 확인하고, 백업 폴더에서
   `sha256sum -c GEAS.tar.sha256`와 AX 백업에 대응하는 `*.sha256` 검증를 실행합니다.
2. 기존 작업 폴더가 유지됐다면 바로 덮어쓰지 말고 필요한 파일을 확인합니다.
3. 복원할 때에는 빈 폴더에 `tar -xf /백업경로/GEAS.tar` 또는
   `tar -xf /백업경로/AXData_focused.tar`로 풉니다. 원래 폴더 구조가 생성됩니다.
4. 새 Git clone에 필요한 데이터·모델 폴더를 복사합니다. GEAS의 `GEAS3.5/`는
   같은 상대 위치로, AXData의 내용은 SmartFarm 저장소의 `AXData/`로 복원합니다.
5. `.env` 등 실제 인증정보는 로컬에만 복원하고 `git status`로 제외 여부를 확인합니다.
6. Python 3.11 환경과 의존성을 확인한 후 `nvidia-smi` 및 PyTorch CUDA 인식을 확인합니다.
7. 테스트와 모델 로드 검증을 실행한 다음 원래 실험의 재개 명령을 사용합니다.

## 실행 중 파일

백업 당시 AX 학습과 GEAS receive-only 수집이 실행 중이었습니다.
TAR는 실행 중 폴더를 순차 복사하므로 모든 파일이 같은 시점의 상태라는 보장은 없습니다.
백업 이후 추가된 관측과 체크포인트는 원래 작업공간에서 별도로 확인해야 합니다.
점검 직전에는 해당 실행을 정상 종료한 후 변경 데이터와 SQLite 상태를 추가로 보존하세요.
컨테이너 재생성 후 기존 PID 파일을 그대로 신뢰하거나 중복 프로세스를 시작하지 마세요.
