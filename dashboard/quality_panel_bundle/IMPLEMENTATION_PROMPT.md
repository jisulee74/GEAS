GEAS_RL을 GEAS 전체 실험 대시보드로 확장하고 데이터 품질 관리 패널을 구현해줘.

GEAS3.5 폴더는 이 환경에 없어. 대신 quality_panel_bundle/README.md, EXPERIMENT_GUIDE.md, source_manifest.json을 먼저 읽고 첨부 data/ 및 reference/만으로 작업해줘.

1. 사이트 제목을 ‘GEAS 실험 대시보드’로 바꾸고 상위 실험 선택 메뉴를 ‘데이터 품질 관리 / 전이모델 선정 / 강화학습 및 제어 실험’으로 구성해줘. 기존 화면·세부 탭·12개 입력 카드·툴팁은 전이모델 선정 아래 유지하고, 강화학습 및 제어 실험은 준비 중으로 표시해줘.
2. 데이터 품질 관리에는 ‘개요 및 처리 과정 / 실험 설정 / 결측·마스킹 복원 / 이상치 탐지 / HPO 및 임계값 / 자원 효율성 / 적용 현황’ 세부 화면을 구성해줘.
3. 작물·모델·Validation/Test 필터를 제공하고 기본은 Validation. 변수별 자료가 있는 화면에만 변수 필터를 제공해줘. 기존 전이모델 필터와 상태는 분리해줘.
4. 통합 CSV 또는 변환 JSON에서 RMSE·MAE·F1·Precision·Recall·MCC·FPR·ROC-AUC·PR-AUC·지연시간·메모리·모델 크기를 읽어 차트와 표로 보여줘. 필터 변경과 다운로드를 지원하고 실제 자료의 단위와 평가 표본 수를 함께 표시해줘.
5. HPO 설정·학습곡선·변수별 임계값은 모델별 파일에서 읽어줘. 최종 임계값 탐색 범위는 injected_validation_scores이며 오래된 설명서 문구를 그대로 사용하지 마. 합성 이상치 검증과 실제 현장 정답 검증, 마스킹 복원과 자연 결측을 구분해줘.
6. 적용 현황은 ‘코드상 기본 적용 모델’과 ‘실제 적용 결과’를 구분해줘. 기본 모델 설정은 문서에 있지만 선정 사유나 적용 완료를 입증하는 자료는 없어. 보정 전후 시계열과 QC 보정 건수는 ‘자료 없음’으로 표시하고 임의로 생성하지 마. 리샘플링/분할 요약을 최종 보정 결과로 표현하지 마.
7. 기존 색상·카드·차트 스타일과 반응형 구조를 유지해줘. 주요 지표는 상호작용 차트로 만들고 PNG는 상세 참고 그림으로 활용해줘. 모델 입력에 대한 품질플래그 ablation은 전이모델 패널에 유지해줘.
8. GEAS_RL만 정적 서버로 실행해도 동작하도록 묶음 내부 상대경로로 로드해줘. reference 소스는 설명 확인용이므로 실행하거나 의존성 설치할 필요 없어. 모델 학습과 원본 실험 산출물 변경은 하지 마.
9. 실제 JSON 구조를 확인하고 구현해줘. 패널 전환·필터·로딩 오류·반응형 화면 및 기존 전이모델 기능을 확인해줘. 사용한 파일과 화면의 대응 관계도 기록해줘.

설명이나 계획만 제시하지 말고 구현까지 진행해줘.
