# GEAS 3.5

최신 소스 정리 기준: 2026-10-29 (GPU MIG 설정 변경 전).

현재 개발 코드는 `GEAS3.5/`에 있습니다. 이 저장소는 소스, 설정, 테스트,
실행 문서와 기존 공개 대시보드 파일을 관리합니다.
원시 데이터, 학습 모델, 실행 로그 및 구버전 복사본은 Git 추적에서 제외하고
서버의 영구 작업공간에 보존합니다. 이전 버전 코드는 Git 이력에서도 확인할 수 있습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `GEAS3.5/src/geas35/` | 전처리·QC·전이모델·RL·온라인 추론·수집 구현 |
| `GEAS3.5/offline_dataset_preparation/` | 데이터 추출 및 데이터셋 생성 스크립트·설정 |
| `GEAS3.5/experiments/` | 품질·전이모델·RL 실험 스크립트·설정 |
| `GEAS3.5/tests/` | 단위·계약·통합 검증 |
| `dashboard/` | 기존 GitHub Pages 대시보드 및 표시용 데이터 |

설치와 실행은 [GEAS3.5 안내](GEAS3.5/README.md), 데이터·환경 복원은
[복구 안내](docs/RESTORE.md)를 참고하세요.

`.env`와 모델·데이터가 없는 새 clone에서는 실제 데이터 실험을 바로 실행할 수 없습니다.
설정 템플릿은 `GEAS3.5/.env.example`입니다. 실제 인증정보는 로컬에서만 관리합니다.
